# Elayne Ink

Website for Elayne Ink: permanent makeup and fine line tattoo.
It has an editorial layout with interactive details, built with plain HTML, CSS and JavaScript. There is no build step.

## Preview
Open `index.html` in a browser.

## Make it yours
- **Email and Instagram:** edit the two constants at the top of `js/main.js`.
- **Prices:** in `index.html`, replace each `$—` in the Services section.
- **Your story, address and deposit policy:** search `index.html` for `[Edit this` and `[Your`.
- **Portrait:** replace the `.portrait-placeholder` block with an `<img>`. The comment in `index.html` shows how.
- **Portfolio photos:** in `js/main.js`, give each item in `WORK` an `img: "images/photo.jpg"`. The line drawings are placeholders.

## Brand colors
Cherry `#8A1F2B` · Wine `#5A1219` · Cream `#F3EADF` · Light cream `#FFFAF4` · Blush `#F2C9CD` · Ink `#1E1012`
These are set once as CSS variables at the top of `css/styles.css`.
